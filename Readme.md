# Real Estate Ecosystem

A complete real estate management ecosystem consisting of a user-facing mobile application and a standalone administration app, both built using Flutter and GetX.

## Repository Overview

This repository contains two Flutter applications:

* **`main_app/`**: The core mobile app for buyers and sellers to discover, rent, buy, and list properties.
* **`admin_app/`**: A standalone administrative dashboard for platform management and user moderation.

---

## Main App Features

* **Unified User Profile:** Access both buyer/renter and seller tools under one account without switching profiles.
* **Property Marketplace:** Browse and search through apartments and real estate available for rent or purchase.
* **Post Listings:** Dedicated workflow to create, publish, and manage property listings directly inside the app.
* **Secure Authentication & OTP:** Protected login system with an integrated OTP (One-Time Password) verification flow for password recovery.
* **Notifications:** Integrated notification system to keep users updated on account activity and listing updates.

---

## Admin App Features

* **User Management:** Review and approve new user registrations.
* **Account Moderation:** Ability to ban or unban accounts to maintain platform security.
* **Listing Oversight:** Monitor active property posts across the platform.

---

## Tech Stack

* **Framework:** Flutter (Dart)
* **State Management & Routing:** GetX
